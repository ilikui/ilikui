## 01 / 关于我

我关注工程实践与知识创造之间的连接：既研究底层软件如何可靠运行，也持续探索如何把学习、阅读和思考沉淀为可复用的系统。

- 🚘 **汽车电子与嵌入式**：Classic AUTOSAR、车载通信、诊断、MCU 与底层软件。
- 🧠 **知识工程**：数字花园、卢曼卡片盒、渐进阅读与间隔复习。
- 🛠️ **开发与自动化**：用脚本、工具链和 CI 工作流减少重复劳动。
- 🌱 **持续创造**：把学习过程整理成教程、示例、图解和可运行项目。

> 不只记录答案，也记录问题之间的联系；不只完成项目，也让下一次实践更容易。

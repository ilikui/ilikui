## 01 / About me

I'm interested in the space between **engineering things that work** and **building systems that help knowledge grow**.

- 🚘 **Automotive & embedded** — Classic AUTOSAR, in-vehicle communication, diagnostics, embedded C and MCU software.
- 🧠 **Knowledge engineering** — digital gardens, Zettelkasten, progressive reading and spaced repetition.
- 🛠️ **Developer tooling** — automation, reproducible examples, CI workflows and practical learning repositories.
- 🌱 **Learning in public** — turning hard-won lessons into clear notes, diagrams, tutorials and useful software.

> I want to build things that are not only useful today, but easier to understand, extend and reuse tomorrow.

## 03 / How I connect ideas

```mermaid
flowchart LR
    A[Curiosity] --> B[Read & Explore]
    B --> C[Atomic Notes]
    C --> D[Connect Concepts]
    D --> E[Build a Tool or Example]
    E --> F[Publish & Review]
    F --> B
    classDef start fill:#312e81,stroke:#a78bfa,color:#fff
    classDef process fill:#0f3440,stroke:#67e8f9,color:#e0f2fe
    classDef output fill:#14532d,stroke:#86efac,color:#f0fdf4

    class B,C,D process
    class E,F output
```

The goal is not to collect more information. It is to make what I learn **findable, connected, testable and useful**.
